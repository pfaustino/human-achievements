# Assets and sources

| Item | Source | Credit |
| --- | --- | --- |
| Invention catalog | [Wikipedia: Timeline of historic inventions](https://en.wikipedia.org/wiki/Timeline_of_historic_inventions) via the MediaWiki API | CC BY-SA 4.0 |
| Curated tiers and “why it matters” notes | `scripts/overrides.mjs` | Project text; does not replace Wikipedia wording on cards |
| Playback / HUD patterns | [Death Atlas](https://github.com/pfaustino/death-atlas) | Same author |

No globe textures are used. The timeline is drawn in canvas.

Refresh the catalog:

```bash
npm run update-data
```
